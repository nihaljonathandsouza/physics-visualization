# Physics Visualization Portfolio

Physics-based educational animations created using **Python** and **Manim Community Edition**.

This portfolio focuses on visualizing concepts from mathematics, optics, and wave physics that can be difficult to communicate through static diagrams alone.

The animations are designed with an emphasis on **conceptual clarity, mathematical representation, and visual intuition**.

## About the Portfolio

These visualizations were developed as independent physics projects to explore ways of communicating mathematical and physical concepts through animation.

The goal is to bridge the gap between **equations, diagrams, and physical intuition** by turning abstract concepts into dynamic visual explanations.
