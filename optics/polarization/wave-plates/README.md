# Wave Plates & Polarization States

A Manim-based visualization of polarization states produced by combining perpendicular electric-field components with different phase relationships.

## Concepts Visualized

- Electric-field components
- Orthogonal polarization components
- Phase difference
- Linear polarization
- Circular polarization
- Elliptical polarization
- Polarization state representation

## Overview

The animation begins by representing the electric field using two perpendicular components.

The relative phase between these components is then varied to demonstrate how their combination determines the resulting polarization state.

Different phase relationships produce different trajectories of the electric-field vector, allowing linear, circular, and elliptical polarization states to be visualized geometrically.

## Mathematics

The electric field can be represented by two perpendicular components:

$$
E_x = A_x\cos(\omega t)
$$

$$
E_y = A_y\cos(\omega t + \delta)
$$

where $\delta$ is the phase difference between the two components.

The resulting polarization depends on the relative amplitudes and phase difference of these components.

For suitable amplitude and phase relationships, the electric-field vector can trace:

- a straight line for linear polarization
- a circle for circular polarization
- an ellipse for elliptical polarization

## Teaching Focus

The visualization provides a geometric way to understand polarization states by showing how two perpendicular electric-field components combine to produce the trajectory of the resultant electric-field vector.

## Implementation

**Software:** Python, Manim Community Edition, NumPy

The animation was created programmatically using vector representations, parametric motion, mathematical expressions, and animated changes in the relative phase of the electric-field components.
